# TraidAIr 🚀

AI 기반 단타 트레이딩 대시보드 & 모의 HTS

## 기능
- 📊 장 전 시장 체크 대시보드 (나스닥·선물·VIX·환율)
- 🤖 Claude AI 실시간 장 전 분석 (시장 방향·섹터·리스크·전략)
- 📈 HTS — 캔들차트 + 보조지표 (MA·RSI·MACD·볼린저·VWAP)
- 🏦 호가창 · 체결창 · 주문창
- ⏯ 모의투자 배속 재생 (x1~x64) + 일시정지
- ⚙ 수수료·손절 한도·비중 설정
- 🛡 뇌동매매 감지 · 손실 한도 경고
- 📓 AI 매매일지 자동 생성 (Claude Sonnet)

## 로컬 실행
```bash
node server.js
```
